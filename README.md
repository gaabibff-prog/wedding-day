# Gabi Wedding Day

A phone app for the wedding day. It keeps upcoming weddings on the phone and opens with no signal.

- Weddings come from the main app as a locked `.gabiday` file (AES-GCM, pairing code).
- Checkmarks and notes go back the same way.
- Nothing is stored in this repository or on any server. Only the app's code lives here.

Open: https://gaabibff-prog.github.io/wedding-day/
